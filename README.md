# Tic Tac Toe

A simple browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Live demo
The game is live on GitHub Pages here:
https://palakaggarwal27.github.io/ticTacToe/

## Features
- Two-player gameplay
- Turn-based X/O logic
- Win and draw detection
- Score tracking across rounds
- Reset button
- Animated win line and polished UI

## How to run locally
1. Open the project folder.
2. Either double-click `index.html` in a browser, or serve it locally:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`

## Project structure
- `index.html` - game layout
- `styles.css` - visual styling and board layout
- `script.js` - game logic and scoring

## Notes
This project is a lightweight front-end game with no external dependencies or build step.
