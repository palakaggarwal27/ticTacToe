# Tic Tac Toe

A simple browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Live demo
The game is live on GitHub Pages here:
https://palakaggarwal27.github.io/ticTacToe/

## About the project
This project was developed as part of the MSc MSIT Web Development Team and demonstrates core web development skills through an interactive browser game.

## Features
- Two-player gameplay
- Turn-based X/O logic
- Win and draw detection
- Score tracking across rounds
- Reset button
- Animated win line and polished UI
- Responsive design for different screen sizes

## How to play
1. Open the game in your browser.
2. Player 1 uses "X" and Player 2 uses "O".
3. Players take turns clicking on empty cells.
4. The first to get three marks in a row wins.
5. If all cells are filled and there is no winner, the game ends in a draw.

## How to run locally
1. Open the project folder.
2. Either double-click `index.html` in a browser, or serve it locally:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`

## Technologies used
- HTML for the game structure and UI
- CSS for styling and layout
- JavaScript for game logic and interactions

## Project structure
- `index.html` - game layout
- `styles.css` - visual styling and board layout
- `script.js` - game logic and scoring

## Notes
This project is a lightweight front-end game with no external dependencies or build step.
